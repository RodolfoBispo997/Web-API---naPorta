# API naPorta

Base inicial de uma API para gerenciamento de pedidos, preparada para evoluir em etapas.

## Stack

- **Configurado:** NestJS 11, TypeScript, npm, lint com Oxlint e execução de testes com Vitest.
- **Planejado, ainda não implementado:** PostgreSQL com Prisma, autenticação JWT Bearer, operações e filtros de pedidos e seed de dados.

Esta etapa não inclui endpoints de negócio, banco de dados ou autenticação.

## Pré-requisitos

- Node.js 20.19 ou superior
- npm 10 ou superior

## Comandos

```bash
npm install
npm run start:dev
npm run lint
npm test
npm run build
```

Ainda não há testes implementados. O comando de testes está configurado para concluir sem erro enquanto não houver arquivos de teste.
